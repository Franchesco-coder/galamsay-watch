About this project

Galamsay Watch was built by Francis Totsi, a 4th-year Geomatic Engineering student at the Kwame Nkrumah University of Science and Technology (KNUST).

This is my first full web application — built to explore how geospatial data, web mapping, and everyday software engineering can come together to support Ghana's fight against illegal small-scale mining (galamsay). It combines anonymous crowd-sourced reporting with automatic geospatial lookups (region, district and town), an interactive live map, and basic analytics, all built from scratch with Python, Flask, PostgreSQL and Leaflet.
